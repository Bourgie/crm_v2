## Alertas

- Sitemap con status distinto de `200`.
- URL indexable con `noindex`.
- Aumento de errores 404.
- Caida de consultas de marca.
- PageSpeed con regresion de Core Web Vitals.
- Cambio no autorizado de datos de contacto.
